The icons below are rendered by `renderIcon()` from [Lucide](https://lucide.dev) icons dumped by the bundle. The
documentation build renders each one with `ux_icon()` too, and fails if the HTML differs: what you see is what Twig
renders. The examples use this configuration:

```yaml
# config/packages/ux_icons.yaml
ux_icons:
    default_icon_attributes:
        width: 1.5em
        height: 1.5em
    icon_sets:
        lucide:
            icon_attributes:
                class: lucide
    aliases:
        delete: 'lucide:trash-2'
```

## An icon

The dumped attributes already carry the configuration: the default size, and the `class` of the icon set.
`aria-hidden="true"` is added, as the icon has no text alternative.
